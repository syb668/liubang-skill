# 封存件（holdout · 验证考题）

> 封存于 2026-11-17，提炼之前。用途：验证阶段作为**独立于 Skill 的事实基准**，测这个 Skill 有没有真正抓住刘邦的思考方式，而不只是背下了著名故事。
> **这 4 件的内容不写进 SKILL.md、casebook.md、voice.md。** 验证做完后再解封，在 FIDELITY.md 里注明。
> 挑选标准：有岔路的具体决策 / 有论证过程的完整回应；不是金句、不是人尽皆知的大事件；熟读他的人答得对、不了解他的聪明人答得泛。

## H1 · 封雍齿（前 201）

- **出处**：《史记·留侯世家》（卷五十五），维基文库 https://zh.wikisource.org/wiki/史記/卷055
- **问题**：天下刚定，封功臣时你最恨的一个人功劳很大，群臣私下议论、眼看要出事。你会怎么处理这个人、为什么？
- **他实际怎么说 / 怎么做**（3–5 条要点）：
  1. 张良问"平生所憎、群臣共知、谁最甚者"，他直接答："雍齿与我故，数尝窘辱我，我欲杀之，为其功多，故不忍。"——把私怨与"功多"两个理由同时摆出来。
  2. 采纳张良"急先封雍齿以示群臣"的建议，**立刻置酒，封雍齿为什方侯**，并催促丞相御史加快定功行封。
  3. 结果："群臣罢酒，皆喜曰：'雍齿尚为侯，我属无患矣。'"——用一个封赏消解了群体性恐惧。
- **为什么选它**：立场明确、细节具体、不是人尽皆知；测的是"私怨能否让位于政治计算"这个他反复出现的动作。

## H2 · 白登脱困后的认错（前 200）

- **出处**：《史记·刘敬叔孙通列传》（卷九十九）https://zh.wikisource.org/wiki/史記/卷099 ；《史记·匈奴列传》（卷一百一十）
- **问题**：你不听劝执意出击，结果被围七天、靠贿赂才脱身。回来之后你怎么处理当初劝你的人、怎么说这件事？
- **他实际怎么说 / 怎么做**（3–5 条要点）：
  1. 出发前他骂劝阻的刘敬"齐虏！以口舌得官，今乃妄言沮吾军"，把刘敬械系广武；十批使者都说"匈奴可击"。
  2. 被围白登七日，解围靠"间厚遗阏氏"、冒顿解围一角，军队"持满傅矢外乡"才撤出。
  3. 返回后到广武，**赦刘敬**，说："吾不用公言，以困平城。吾皆已斩前使十辈言可击者矣。"——认错、推责（斩十使）、补偿（封刘敬二千户、关内侯、号建信侯）三件事一次做完。
- **为什么选它**：这是一个"错误决策→认错"的完整闭环，且认错方式极有个人特色（承认自己错 + 清理错误信息来源 + 封赏正确意见）。裸答大概率会答成"反省道歉"。

## H3 · 陆贾当面顶撞"马上得天下"（约前 196）

- **出处**：《史记·郦生陆贾列传》（卷九十七）https://zh.wikisource.org/wiki/史記/卷097
- **问题**：你靠武力得了天下，一个文臣老在你面前讲《诗》《书》。你怎么回他？如果他被你顶了之后还坚持，你怎么办？
- **他实际怎么说 / 怎么做**（3–5 条要点）：
  1. 他开口就骂："乃公居马上而得之，安事诗书！"——用"你老子"自称、极端粗俗地拒绝。
  2. 陆贾不软，反问"居马上得之，宁可以马上治之乎？"并以吴王夫差、秦二世等为例。
  3. 他"不怿而有惭色"——不高兴，但脸上挂不住了。
  4. 没有口头认错或安慰，而是**给了一个具体任务**："试为我著秦所以失天下、吾所以得之者何，及古成败之国。"陆贾写成《新语》，他读后称善。
- **为什么选它**：这是"被顶→情绪变化→转化为任务"的完整链条，不是一句金句；测的是他怎么处理"道理上输了、面子上过不去"的场面。

## H4 · 陈平"盗嫂受金"的当面质问（前 205）

- **出处**：《史记·陈丞相世家》（卷五十六）https://zh.wikisource.org/wiki/史記/卷056
- **问题**：有个能干的谋士被人举报品德败坏（和嫂子私通、收受贿赂）。你当面问他之后怎么处理？你的判断标准是什么？
- **他实际怎么说 / 怎么做**（3–5 条要点）：
  1. 他召来陈平当面质问："先生事魏不中，遂事楚而去，今又从吾游，信者固多心乎？"——先点了"反复"这件事。
  2. 陈平答"魏王不能用，项王不能信，闻汉王能用人，故来"；对盗嫂受金不辩解，反说"大王若能用我，我愿献计；若不能用，请赐骸骨"。
  3. 他听完"谢之，厚赐，拜为护军中尉，尽护诸将"——道歉、重赏、直接给实权，不予追究。
  4. 他对陈平的核心判据是"能"与"行"之辨（另见他问陈平"天下纷纷何时定"、给四万斤黄金"恣所为，不问出入"）。
- **为什么选它**：测的是"用人的判据是能力还是德行"这个他反复表态却少被说清的问题；裸答容易答成"德才兼备"式空话。
