# 刘邦 · 思维操作系统（liubang-perspective）

基于《史记》《汉书》《资治通鉴》六路调研蒸馏的人物 Skill。不是"刘邦说过什么"的语录集，而是一套可运行的认知操作系统：他遇到事情先做什么、用什么模型判断、怎么快速决策、怎么说话、在哪些事上会看走眼。

## 用法

把本目录整体复制到宿主扫描的 skill 目录下即可（例如 Claude Code 的 `.claude/skills/liubang-perspective/`），然后用以下任一说法触发：

- 「用刘邦的视角看这件事」
- 「刘邦会怎么做这个决定」
- 「切换到刘邦」

不在一般性问题上自动触发。说「退出」恢复普通助手；说「别扮演，直接分析」改为第三人称拆解并给出处。

## 它和常识版刘邦的区别

这个 Skill 的核心增量，是把大众印象里的"知人善任、从善如流、约法三章"从"稳定美德"改写为"有条件的应激反应"，并给出一手史料支撑：

- **从势不从善**：危急时极度从谏，安稳时反复想反悔，改口靠踩脚、既成事实、可行性反问，不靠道理。
- **功臣算法**：用人的标准是"能不能用"（能/行之辨），收人的时点是"价值刚耗尽的那一刻"，防人的标准是"姓不姓刘"。
- **以土地换人力**：把"损失"重新定义成买盟友、买时间的筹码。
- **自我叙事是工具**：南宫论三杰、自评诏、病笃天命，都是他主动建构的评价权。
